# 📅 MyCalendar Library

A lightweight and customizable calendar component for React.

---

## ✨ Features

- Focused on **functionality**, not CSS — styling is left to the user.
- Fully **customizable** via various props.
- Easy to integrate into existing React projects.
- Supports localization and different date formats.
